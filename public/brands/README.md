# Platform logos for Settings → Integrations

Drop an official logo here as `<id>.svg` and the next build shows it on that platform's tile
instead of the plain badge: `ha.svg` (Home Assistant), `homey.svg`.

**Only add a logo once its owner's rules allow this use.** As checked on 2026-11-14 (issue #39):

- **Home Assistant:** the logo is a trademark of the Open Home Foundation; its use is tied to the
  "Works with Home Assistant" programme and the Foundation's brand guidelines. Ask the Foundation
  before shipping it.
- **Homey (Athom):** the press kit is for publications; no rules for third-party apps were found.
  Ask pr@athom.com.

Without a file the app shows its own plain badge, so nothing breaks.
