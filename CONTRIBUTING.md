# Contributing to Nidorama

Thank you for wanting to help. Nidorama is developed in the open, and ideas, bug reports and code
are all welcome.

## Ideas and problems

Use the app (More → Requests) or open an issue on this repository. Say what you were doing, what
happened, and what you expected. Other people can vote on a request with a thumbs-up; the owner
decides what is built and when.

## How changes are released

Every change is built first as an **Alpha** build. When an Alpha build has proved itself the
owner promotes that same build to **Beta**, and later to **Stable**. Nothing skips a stage. You
can choose which builds your device receives in Settings → Updates.

## Code

1. Open an issue first for anything more than a small fix, so the approach can be agreed.
2. Fork the repository, make your change on a branch, and open a pull request against `main`.
3. Keep to what the project is: everything local, nothing about any particular home built in,
   a small calm interface that runs well on a mid-range wall tablet.
4. Never include anything personal: no real home files, addresses, device names, tokens or keys.
